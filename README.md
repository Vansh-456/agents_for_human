# AnnaSetu — Autonomous Food-Rescue Coordination Agent

> **Track:** Good Neighbor Agents (AWS Agents for Humans Hackathon)

AnnaSetu is an autonomous coordination system designed to rescue surplus food from donors and seamlessly match it with community organizations. It actively monitors for donor reports, checks recipient capacity, handles logistics by engaging riders, and continuously re-plans whenever disruptions occur—all while enforcing deterministic safety boundaries (AnnaGuard) over its multi-agent Strands Bedrock workflow.

## The Problem
Food surplus events are time-critical and unpredictable. When a restaurant has 45 meals remaining after service, they must coordinate safe transport and recipient availability within a narrow window before the food expires. Expecting humans to manually cross-reference driver availability and charity capacity in a panic leads to wasted food.

## Target Users
1. **Donors (Restaurants, Caterers):** Report surplus quickly via natural language (e.g. WhatsApp).
2. **Community Kitchens (Recipients):** Update their active capacity and operating hours.
3. **Delivery Partners (Riders):** Accept dynamic routing for food rescue.
4. **Operations Hub (Human Operators):** Handle tied allocations or explicit safety blocks generated by the deterministic control plane.

## Architecture & Real Workflow

The system utilizes the **Strands Agents SDK** executing on **Amazon Bedrock**.

1. **Signal Agent:** Parses incoming natural-language text into strongly-typed `SurplusDraft` schemas.
2. **Supervisor Agent:** Orchestrates the durability queue, handling state transitions.
3. **Allocation / Logistics Agents:** Determine the best possible routing given live availability constraints.
4. **AnnaGuard (Deterministic Policy):** A strict evaluation plane that prevents any LLM from approving expired food or impossible ETAs. All AI outputs are checked against this engine. If blocked, the workflow requests a Human Decision.

### AWS Services Utilized
- **Amazon Bedrock (AgentCore where available):** Core inference engine for the Strands Agents.
- **Amazon DynamoDB:** Handles durable state, reservations, and idempotency for all workflow records.
- **Amazon SQS / EventBridge:** Reliable background async queues for workflow transitions (`RIDER_UNAVAILABLE`, `SURPLUS_REPORTED`).
- **AWS App Runner / Lambda:** Powers the secure backend FastAPI service.
- **Amazon S3 & CloudFront:** Hosts the React + Vite Frontend application.
- **Amazon Cognito:** Manages auth controls and organizational RBAC.

## Data Provenance & Safety Model
- **Data Source:** Seed data for the Delhi NCR pilot utilizes public mapping aggregates. It does **not** include real personal data, private addresses, or PII.
- **AnnaGuard Safety Bounds:** Calculates safety based on `food_category` prep times, travel ETAs, and pickup limits. LLMs have **no capability** to bypass these boundaries. If the AI suggests an unsafe route, the system blocks the plan deterministically.

## Running Locally

To run the full simulation dashboard and backend without paid credentials:

```bash
# 1. Install Backend
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt boto3 pytest
export MOCK_AWS=true
export PYTHONPATH=.
python main.py

# 2. Install & Start Frontend (in a new terminal)
cd frontend
npm install
npm run dev
```

## Testing

Ensure you are in the project root with the virtual environment activated:
```bash
export MOCK_AWS=true
export PYTHONPATH=.
pytest tests/
```

## AWS Deployment (CDK)

Deploy the entire production architecture into your AWS account using AWS CDK:
```bash
cd infrastructure
npm install
npx cdk deploy
```

**Environment Variables Required for Production:**
- `MOCK_AWS=false`
- `BEDROCK_MODEL_ID` (e.g., `anthropic.claude-3-haiku-20240307-v1:0`)
- `AWS_DEFAULT_REGION`
- `CORS_ORIGINS`

## Cost & Cleanup

This infrastructure utilizes Serverless components and Pay-Per-Request DynamoDB. The idle cost is near-zero (S3 storage only). 
To destroy all resources and avoid future charges:
```bash
cd infrastructure
npx cdk destroy
```

## Guided Demo Scenarios

The web application exposes `/demo` trigger buttons demonstrating:
1. **Normal Rescue:** Immediate extraction, allocation, and assignment.
2. **Rider Failure → Re-plan:** An assigned rider drops out; the system automatically re-evaluates capacity and reassigns without human intervention.
3. **Safety Block:** An LLM-proposed route takes too long. AnnaGuard catches the violation, prevents assignment, and flags for operator review.
4. **Missing Details:** Donor forgets to state the quantity; the AI politely asks for clarification rather than hallucinating facts.
